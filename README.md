# London Tamil Sangam — Class 3 study plan

Open `mundram-vaguppu-paadathittam.html` in a browser.

This is the Class 3 (மூன்றாம் வகுப்பு) Tamil Language School **study plan and scheme of work** for [The London Tamil Sangam](https://www.ltsuk.org/) (charity 1097724), academic year 2025–2026.

It is written for teachers, parents and pupils at the East Ham, Redbridge and online branches.
